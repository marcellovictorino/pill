pill runs the Pi coding agent against local language models served by llama.cpp's llama-server. Apple Silicon Macs only for now.

Get started GitHub

Runs on your Mac

pill runs a local model that fits your machine, with Apple Silicon (M-series) in focus. pill catalog lists the models pill can download and shows the variant recommended for this machine's RAM.

Everything stays on your computer: no account, no API key, no per-token bill.

Pi, the lightest harness

pill opens the Pi coding agent (github.com/badlogic/pi-mono). Pi is a deliberately minimal coding harness, so its prompt and tool overhead leave more of a local model's limited context window for your code.

Built on giants

pill is a thin wrapper around llama.cpp (github.com/ggml-org/llama.cpp), adding the convenience and ergonomics people know from Ollama.

$ pill catalog what pill can download, with the variant recommended for your RAM
$ pill pull <name> download a model (resumes, verifies sha256)
$ pill add <name> --unverified register it with the router and Pi
$ pill ls list local models and their state (pulled, unverified, passed, failed, missing)
$ pill default <name> choose the default model
$ pill ps router state, port, loaded model and its memory
$ pill serve start the router for any OpenAI-compatible client (http://127.0.0.1:11435/v1)
$ pill stop unload the model and free memory
$ pill there is no run command. Bare pill starts the router if needed and opens Pi on your default model.

Benchmarked in tiers, hunting a champion

pill bench run <name> gates every model: Tier 1 is a cold-start reply check, Tier 2 is a coding task scored by a hidden verifier (22/22 required), and the separate Tier 3 evaluations (Go, Python and web tasks including landing pages) show where each model is strong.

The benchmark is re-run as new models are released or llama.cpp gains new flags, always looking for a new Champion. Current champion: MiniCPM-V 4.7 IQ2, which passed Tier 2 in 5 of 5 runs at about 25 tokens per second.

Install

Requirements:

brew install llama.cpp
brew install pi-coding-agent

Install pill:

go install github.com/marcellovictorino/pill@latest

Then:

pill pull gemma4-26b
pill add gemma4-26b-iq4xs-64k --unverified
pill
