01 · Local

Runs on your Mac.

pill runs a local model that fits your machine. Apple Silicon (M-series) Macs are the focus, and the only platform for now.

Sized to your machine

Built for Apple Silicon M-series Macs, running a local model that fits the machine in front of you.

pill catalog

Lists the models pill can download and shows the variant recommended for this machine's RAM.

Stays on your computer

  • No account
  • No API key
  • No per-token bill

02 · Harness

Pi, the lightest harness.

pill opens the Pi coding agent (opens in a new tab). Pi is a deliberately minimal coding harness.

Local models have limited context windows. Because Pi keeps its prompt and tool overhead small, more of that window is left for your code.

With 64k context window as default

Enough for real agent work, not a toy chatbot with 5 message history.

--ctx can be used to reduce the context window if needed.

03 · Foundations

Built on giants.

pill is a thin wrapper around llama.cpp (opens in a new tab), adding the convenience and ergonomics people know from Ollama.

~ pill
  • pill catalogwhat pill can download, with the variant recommended for your RAM
  • pill pull <name>download a model (resumes, verifies sha256)
  • pill add <name> --unverifiedregister it with the router and Pi
  • pill lslist local models and their state: pulled, unverified, passed, failed, missing
  • pill default <name>choose the default model
  • pill psrouter state, port, loaded model and its memory
  • pill servestart the router for any OpenAI-compatible client at http://127.0.0.1:11435/v1
  • pill stopunload the model and free memory
  • pillstart the router if needed and open Pi on your default model
no run

There is no pill run command. Bare pill starts the router if needed and opens Pi on your default model.

04 · Benchmarks

Benchmarked in tiers, hunting a champion.

pill bench run <name> gates every model. The benchmark is re-run as new models are released or llama.cpp gains new flags, always looking for a new Champion.

  1. Tier 1 · gate

    Cold start

    A cold-start reply check.

  2. Tier 2 · gate

    Coding task

    Build a tic-tac-toe engine and CLI in Node.js, checked by 22 hidden tests. All must pass.

  3. Tier 3 · separate evaluations

    Real-world tasks

    Bigger, more varied work that shows where each model is strong:

    • Fixing a CLI in Go
    • Analysing data in Python
    • Building landing pages
    • Building a single-page app in TypeScript

05 · Install

Take your first pill.

Apple Silicon Mac, Homebrew and Go. Six steps from nothing to a local coding agent.

  1. 1Requirements

    brew install llama.cpp && \
brew install pi-coding-agent

  2. 2Install pill

    go install github.com/marcellovictorino/pill@latest
echo 'export PATH="$HOME/go/bin:$PATH"' >> ~/.zshrc

  3. 3Turn on tab completion (zsh) optional

    echo 'source <(pill completion zsh)' >> ~/.zshrc

    Open a new terminal, then pill bench run mini and Tab fills in the model name.

  4. 4Check the setup

    pill doctor

    Confirms llama.cpp and Pi are found. pill never installs them for you.

  5. 5Pull, test and register the champion

    pill bench run minicpm-v4-7

    Downloads MiniCPM-V 4.7 IQ2 (11.3 GB), runs the tier 1 and 2 gate on your Mac and registers it with Pi only if it passes. A run can take up to about 25 minutes, and tier 2 needs Node.js. Run pill catalog to see what is measured on your device.

  6. 6Go
