Built on giants.

The power of llama.cpp, with a little more comfort.

pill is a thin wrapper around llama.cpp, adding the convenience and ergonomics people know from Ollama.

THE PILL TOOLKIT● LOCAL
pill catalog

See downloadable models and the variant recommended for your RAM.

pill pull <name>

Download a model; resumes and verifies SHA-256.

pill add <name> --unverified

Register it with the router and Pi.

pill ls

List local models and their state: pulled, unverified, passed, failed or missing.

pill default <name>

Choose the default model.

pill ps

Show router state, port, loaded model and its memory.

pill serve

Start the router for any OpenAI-compatible client at http://127.0.0.1:11435/v1.

pill stop

Unload the model and free memory.

pill

Start the router if needed and open Pi on your default model. There is no run command.

Benchmarked in tiers,
hunting a champion.

Every model goes through the gate.

pill bench run <name> tests models in tiers. Separate Tier 3 evaluations use Go, Python and web tasks, including landing pages, to show where each model is strong.

The benchmark is re-run as new models arrive or llama.cpp gains new flags, always looking for a new Champion.

01

Install requirements

brew install llama.cpp
brew install pi-coding-agent
02

Install pill

go install github.com/marcellovictorino/pill@latest
03

Choose a model and start

For example, using a model from the catalog:

pill pull minicpm-v4-7
pill add minicpm-v4-7-adiq2xsiq2xxs-64k --unverified
