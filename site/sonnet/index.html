01 · Runs on your Mac

A model that fits your machine.

pill runs a local model sized for your Mac, with Apple Silicon (M-series) in focus. Apple Silicon Macs only for now.

M

Sized to your RAM

pill catalog lists the models pill can download and shows the variant recommended for this machine's RAM.

Everything stays here

Your code and prompts stay on your computer. The model is served locally by llama.cpp.

No bill, no keys

No account, no API key, no per-token bill.

02 · Pi, the lightest harness

Less harness, more context for your code.

pill opens the Pi coding agent. Pi is a deliberately minimal coding harness, so its prompt and tool overhead leave more of a local model's limited context window for your code.

03 · Built on giants

A thin wrapper around llama.cpp.

pill wraps llama.cpp and adds the convenience and ergonomics people know from Ollama.

pill
  • pill catalogwhat pill can download, with the variant recommended for your RAM
  • pill pull <name>download a model (resumes, verifies sha256)
  • pill add <name> --unverifiedregister it with the router and Pi
  • pill lslist local models and their state (pulled, unverified, passed, failed, missing)
  • pill default <name>choose the default model
  • pill psrouter state, port, loaded model and its memory
  • pill servestart the router for any OpenAI-compatible client (http://127.0.0.1:11435/v1)
  • pill stopunload the model and free memory
  • pillthere is no run command. Bare pill starts the router if needed and opens Pi on your default model.

04 · Benchmarked in tiers

Hunting a champion.

pill bench run <name> gates every model. The benchmark is re-run as new models are released or llama.cpp gains new flags, always looking for a new Champion.

  1. Tier 1

    Cold-start reply

    A check that the model replies after a cold start.

  2. Tier 2

    Hidden verifier

    A coding task scored by a hidden verifier. 22/22 required.

  3. Tier 3

    Strengths

    Separate evaluations (Go, Python and web tasks including landing pages) show where each model is strong.

  4. Current champion

    MiniCPM-V 4.7 IQ2

    5/5Tier 2 runs passed ~25tokens per second

05 · Install

Three steps, then pill.

Requirements

brew install llama.cpp
brew install pi-coding-agent

Install

go install github.com/marcellovictorino/pill@latest

Then

pill pull gemma4-26b
pill add gemma4-26b-iq4xs-64k --unverified
pill

gemma4-26b is just an example from the catalog. Run pill catalog to see the rest.
